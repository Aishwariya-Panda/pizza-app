Pizza App:

A simple full-stack Pizza Ordering Web Application built using:

- Java 17
- Spring Boot
- Thymeleaf
- Maven
- Docker
- Render (Cloud Deployment)
Live Application

Order Pizza Here:  
https://pizza-app-uojx.onrender.com/

Features:

- Select Pizza Type
- Choose Size (Small / Medium / Large)
- Add Custom Toppings
- Enter Quantity
- Automatic Total Price Calculation (₹ INR)
- Clean UI with Order Summary Display
- Deployed on Render Cloud

---

language used:

| Layer      | Technology        |
|------------|-------------------|
| Backend    | Spring Boot       |
| Frontend   | Thymeleaf + HTML  |
| Build Tool | Maven             |
| Deployment | Render            |
| Container  | Docker            |
